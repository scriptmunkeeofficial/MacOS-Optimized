## [1.2.2] - 2026-09-18

### Added
- Update for Minecraft 26.2 with Fabric Loader 0.19.5.

### Changed
- Updated 24 mods: 3D Skin Layers, Better Block Entities, Capes, Cloth Config API, Elytra Contrails Mod, Entity Culling, [ETF] Entity Texture Features, Fabric API, Fabric Language Kotlin, ImmediatelyFast, Iris Shaders, LambDynamicLights, Lithium, MacOS Input Fixes, Mod Menu, More Culling, Reese's Sodium Options, Shulker Box Tooltip, Simple HUD Enhanced, Simple Voice Chat, Sodium Extra, Sodium, YetAnotherConfigLib, Zoomify.
- Updated 6 shaderpacks: BSL Shaders, Complementary Shaders - Reimagined, Complementary Shaders - Unbound, MakeUp - Ultra Fast, Mellow, Miniature Shader.
- Updated resource packs: Translations for Sodium.
- Config updates: Default shader pack set to Mellow Shader v3.2 in `iris.properties`.

## [1.2.0] - 2026-05-17

### Added
- Minecraft 26.1 (Tiny Takeover) support with Fabric Loader 0.149.0+26.1.2.
- Added LambDynamicLights, Better Block Entities, Elytra Contrails Mod.

### Changed
- Major updates: Sodium, Lithium, Fabric API, Mod Menu.
- Updated 3D Skin Layers, Iris Shaders.
- Compatibility updates across remaining mods, shaderpacks, and resource packs.
- Configuration tuning for `options.txt`, `entityculling.json`, `iris.properties`, `simplehudenhanced.toml`, and `zoomify.json`.

### Removed
- Legacy `config/dynamic_fps.json` removed.
